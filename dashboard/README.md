# GEcko research dashboard

Interactive presentation of the results from the GEcko statistical-arbitrage
study. The dashboard is intended as a concise companion to the main project
methodology, not as a live trading interface.

**Live site:** https://gecko-research-dashboard.greenwoodtom.chatgpt.site

## What it covers

- the eight-pair candidate screen and rejection reasons
- rolling two-year cointegration diagnostics
- walk-forward OU signal construction
- tax-only and measured-spread backtest results
- Grand Exchange buy-limit capacity scenarios
- OU, logistic-regression, and gradient-boosting comparisons
- lookahead-audit results and research limitations

The figures and reported values come from the committed outputs in the parent
GEcko repository. The dashboard does not fetch live prices or expose parameters
for in-sample optimisation.

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

The development server is available at `http://localhost:3000` by default.

## Validate

```bash
npm run lint
npm test
```

`npm test` creates a production build and checks that the finished research
content, interactions, and social-preview assets are present in the rendered
output.

## Main files

- `app/research-dashboard.tsx` — content, verified project values, and controls
- `app/globals.css` — responsive visual system
- `public/research/` — figures generated by the main Python research pipeline
- `tests/rendered-html.test.mjs` — production-render checks
